# Seat Radar Live (SEATRADAR) — מקומות פנויים בקורסי הטכניון

מפת תפוסה ומקומות פנויים בקורסים וקבוצות רישום בטכניון.

🔗 **לאתר החי:** [seatradar.live](https://seatradar.live/)

## מה אפשר לעשות באתר
- חיפוש מהיר לפי שם קורס, מספר קורס (ישן או חדש), פקולטה, ענף ספורט, מרצה, בניין או יום בשבוע.
- סינון מהיר למל״גים פתוחים, קורסי ספורט פתוחים, מקומות אחרונים, נק״ז ורשימת מעקב אישית.
- צפייה במקומות פנויים, תפוסה, שעות, מיקומים, סילבוס ותאריכי בחינות לכל קבוצת רישום, ומעבר ישיר לרישום ולקטלוג הטכניון.
- מותאם לכל סוגי המסכים (מובייל, טאבלט ומחשב) כולל מצב כהה ובהיר.
